Things I have built

Iris

A macOS menu bar app that makes you rest your eyes, and blocks the things that pull you away while you work.

Every eye-break app on the Mac reminds you to look away. Every focus app blocks distractions. Nothing does both, so you end up paying for two. Iris does both in one native app: 20-20-20 breaks, on-device posture detection using the Vision framework, and an app and website blocker that runs while you work. It holds a break back if you are mid-sentence, which is the thing people actually uninstall these apps over.

Ziggy's Critters

A quiz game for kids, with a console their parents can actually use.

Kids answer questions, collect critters and message each other. Parents get a separate console to see progress and read what has been sent. Built for real children using it daily, which means the boring parts matter most: locked-down row-level security, hashed PINs, and a client that fails gracefully rather than telling a nine year old their correct PIN is wrong.

Fitcheck

A wardrobe app that picks what you wear based on the weather outside.

Photograph your clothes once, and it suggests outfits that match the forecast and do not clash. Everything is stored locally in the browser, no account. Dark editorial design, built to feel like a magazine rather than a database.

Switchboard

An iMessage-style chat client for talking to a team of AI agents.

One inbox for a group of agents that each run somewhere different, over a CLI, an HTTP API, or Slack. Five adapters behind one interface, so a conversation looks the same whether the thing answering is a local process or a bot in a Slack channel.

How I work

I would rather ship one thing that works than five that almost do. Most of what I have learned came from killing projects that had no reason to exist.

on scope

Native when it matters. An app that lives in your menu bar all day should not be a browser in a trench coat.

on tools

If something is broken I would rather find it than be told it is fine. Most of the work on Ziggy was security nobody will ever see.

on quality

Nothing I build phones home unless it has to. No accounts where a local file will do.
